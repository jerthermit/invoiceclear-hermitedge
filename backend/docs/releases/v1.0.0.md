# InvoiceClear v1.0 — Public Portfolio Release

InvoiceClear helps billing teams investigate missing or mismatched purchase orders and prepare billing handoffs for human approval.

- Review invoices, original PO documents, correspondence and evidence-linked discrepancies in one case.
- Enable TogetherAI investigation with a backend key. Each run starts after confirmation, cites the inspected sources and proposes a next step.
- Approve and export a billing handoff with the original PO, approval record and billing lines. Approval does not send email, update accounting or mark an invoice paid.
- Try the 36-case fictional workload with a matching CSV/PDF source bundle. The frontend runs on Vercel; Railway hosts the API and SQLite storage.

**Scope:** One shared walkthrough workspace with fictional records. Live investigation needs a TogetherAI account. Connected Gmail and QuickBooks actions are private-mode only and require separate setup and consent.
